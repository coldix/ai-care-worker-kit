# Check my invoice meets requirements

Use this before you send an invoice, to catch the mistakes that get invoices sent back.

## Copy and paste this

```text
Check this invoice to a Support at Home provider before I send it. I'm an Australian sole trader [registered / not registered] for GST.

Check that it has: my name or registered business name and ABN, a unique invoice number and date, the provider's name, a client reference, one line per visit with date, official service type, description, hours, rate and amount, correct maths, a total, the right GST wording ("Invoice" and "No GST has been charged" if not registered), payment terms and bank details. Flag vague descriptions, travel lines and anything that looks like more hours than usual.

List problems first, then a corrected version.

[PASTE YOUR INVOICE, WITH CLIENT CODE INSTEAD OF NAME]
```

## Privacy note

Swap the client's name for a code before you paste, then put it back on your final copy.

Always read the answer before you use it, and check every number yourself.
