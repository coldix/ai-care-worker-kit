# Work out tax to set aside

Use this to get a rough idea of how much of each payment to put away for tax. It's an estimate, not tax advice.

## Copy and paste this

```text
I'm an Australian resident sole trader doing aged care work. Help me estimate how much of each payment to set aside for income tax and the Medicare levy.

Expected business income this financial year: $[AMOUNT]
Expected business expenses: $[AMOUNT]
Other income (job, pension, etc): $[AMOUNT]

Use the current ATO resident tax rates and say which year's rates you used. Show the working step by step, then give me a simple percentage to move into savings from each payment. Remind me to check the result against the ATO's own calculators or a registered tax agent.
```

## Privacy note

No client details are needed. Avoid pasting your tax file number or bank details.

Always read the answer before you use it, and check every number yourself.
