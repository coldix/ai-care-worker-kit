# Build a weekly timesheet

Use this to turn scrappy phone notes into a tidy timesheet table you can keep and invoice from.

## Copy and paste this

```text
Turn my notes below into a weekly timesheet table with these columns: Date, Client code, Start, Finish, Hours, Service type, What I did, Km (if agreed).

Work out hours from start and finish times, in decimals (2.5 not 2:30). Add a total hours row, and a total per client code. If anything is unclear or missing, list it under the table as a question instead of guessing.

Week starting [MONDAY DATE]. My notes:
[PASTE NOTES, USING CLIENT CODES]
```

## Privacy note

Use codes like "Client A" and keep a private list that matches codes to real clients. Don't include addresses or anything about a client's health.

Always read the answer before you use it, and check every number yourself.
